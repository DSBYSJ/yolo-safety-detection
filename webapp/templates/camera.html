接入监控摄像头

当前未检测到可用的视频源。 本页支持两种接入方式 —— 推荐用 RTSP 网络摄像头（海康威视、大华等）， 画面质量与工地场景更贴合；手边没有设备时，可先用手机推流快速验证。

适用于海康威视 / 大华 / 宇视等支持 RTSP 的 IP 摄像头或 NVR。

  1. 确认摄像头与运行本系统的电脑在同一局域网（同网段，能互相 ping 通）。
  2. 在摄像头管理后台开启 RTSP（海康默认端口 554）。
  3. 拼出取流地址，常见格式：
    • 海康威视：rtsp://admin:密码@摄像头IP:554/Streaming/Channels/101
      101 = 主码流（高清），102 = 子码流（流畅，检测够用）
    • 大华：rtsp://admin:密码@摄像头IP:554/cam/realmonitor?channel=1&subtype=0
  4. 启动服务时指定地址（Windows 下用 run_web.bat 可直接改）： 
    set CAMERA_SOURCE=rtsp://admin:密码@192.168.1.64:554/Streaming/Channels/102
scripts\run_web.bat
不确定地址对不对？先用探测脚本验证，能取到画面再启动服务： 
python scripts\list_cameras.py --url "rtsp://admin:密码@192.168.1.64:554/Streaming/Channels/102" --save

适用于手边没有 IP 摄像头时，用手机 App 快速搭一个视频源。

  1. 手机装 IP Webcam（Android，免费）或同类 App。
  2. 打开 App 点「启动服务器」，记下显示的地址（形如 http://手机IP:8080）。
  3. 取流地址在其后加 /video： 
    set CAMERA_SOURCE=http://192.168.1.100:8080/video
scripts\run_web.bat
  4. 先用浏览器直接打开该地址，能看到画面说明地址正确。
💡 也可以用本系统的「手机检测」页 —— 手机浏览器直接开摄像头， 逐帧发给电脑推理，不用装任何 App，更适合现场随手测。
排查提示：改了地址后必须重启服务才生效；若地址不可达， 抓帧线程会每 5 秒自动重试并在画面上显示原因。
