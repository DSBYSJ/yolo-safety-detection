# 迁移说明 —— 换电脑后怎么把它跑起来

本包是「安全帽 / 口罩佩戴检测系统」的可运行快照，已包含**源码 + 模型权重 + 证书**，
解压后只需装一次依赖即可运行，不需要重新训练、不需要重新下载模型。

---

## 一、包内有什么

| 内容 | 说明 |
| --- | --- |
| `webapp/` | 应用主体（Flask + 模板 + 静态资源） |
| `models/helmet.pt` `models/mask.pt` | 检测权重，**已包含**，无需再训练 |
| `models/face/` | 人脸识别模型 buffalo_l（187MB），**已包含** |
| `certs/` | HTTPS 自签证书 —— 手机端调摄像头必须走 HTTPS |
| `scripts/` `train/` `tests/` | 启动、训练、测试脚本 |
| `docs/` | 界面截图与文档配图 |
| `requirements.txt` | Python 依赖清单 |
| `README.md` | 完整项目文档 |
| `.gitignore` | Git 排除规则（保留，便于继续开发） |

## 二、包里**没有**什么（按需自行准备）

按体积与可再生原则刻意未打包，日常开发运行用不到，只在特定场景才需要：

| 未包含 | 何时才需要 | 怎么补 |
| --- | --- | --- |
| `datasets/`（4.1GB） | 要**重新训练**模型时 | 用 `scripts/` 里的下载脚本，或从原机拷 |
| `runs/`（197MB） | 要回看历史训练曲线 / 中间权重时 | 从原机拷贝 |
| `webapp/uploads/` 里的图片 | 要保留历史上传图片时 | 从原机拷贝 |
| `webapp/data.db` | 要保留历史检测记录 / 打卡数据时 | 从原机拷贝 `webapp/data.db` |
| `webapp/static/faces/` | 人脸底库登记照 | 从原机拷贝（**含真人照片，注意保密**） |
| `pretrained/` | 一般不需要 | 由 ultralytics 自动下载 |
| `.venv/` | —— | 新机器上重新创建（见第三步） |

> **数据库（`webapp/data.db`）与人脸底库照片（`webapp/static/faces/`）刻意未打包**：
> 前者属个人运行数据，后者属个人生物特征信息。应用首次启动会**自动重建空库与空目录**，
> 所以不放进来也能正常运行。
>
> 想连历史数据与已登记人脸一起带走，就把原机的 `webapp/data.db` 与
> `webapp/static/faces/` 复制到本包的 `webapp/` 下即可。

## 三、新电脑上的启动步骤（3 步）

### 前置：装 Python 3.10 ~ 3.13

到 python.org 下载安装，**勾选 "Add Python to PATH"**。

### 第 1 步：创建虚拟环境并装依赖

在包根目录（本文件所在目录）打开命令行：

```bat
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
```

**如果有 NVIDIA 显卡**，再装 CUDA 版 PyTorch 以启用 GPU 加速（按你的 CUDA 版本选）：

```bat
.venv\Scripts\pip install torch torchvision --index-url https://download.pytorch.org/whl/cu124
```

没有独显就跳过这步，会自动用 CPU 跑（慢一些但能用）。

### 第 2 步：启动

双击 `scripts\run_web.bat` 即可（它会自动找到 `.venv` 里的解释器）。

或手动启动：

```bat
.venv\Scripts\python -u webapp\app.py
```

### 第 3 步：访问

- 本机：`https://127.0.0.1:5000`
- 手机：`https://<本机局域网IP>:5000`（启动横幅里会打印出来）

> 首次访问浏览器会提示证书不受信任 —— 证书是自己签的，点「继续前往 / 高级 → 继续访问」即可。
> 这不是故障，而是自签证书的正常表现。

## 四、换机器后可能要做的小调整

### 摄像头索引

`scripts\run_web.bat` 里默认 `CAMERA_INDEX=1`（原机上内置摄像头是 0、外接是 1）。
**换电脑后索引很可能不同**，表现为「打开摄像头一直黑屏」。

排查办法：

```bat
.venv\Scripts\python scripts\list_cameras.py
```

它会逐个索引试开并报告哪个能用，然后把 `run_web.bat` 里的 `CAMERA_INDEX` 改成可用值。

> 想用手机当摄像头，见 `README.md` 的「六之三 / 六之四」。

### 端口被占用

`run_web.bat` 已内置清理逻辑：启动前会自动结束占用 5000 端口的旧进程。

## 五、安全提示（重要）

⚠️ 本包含以下**敏感内容**，请仅限本机自用，**不要**传到公开仓库、群聊或网盘：

| 文件 | 为什么敏感 |
| --- | --- |
| `certs/key.pem` | HTTPS 私钥 |
| `webapp/static/faces/`（若你手动拷入） | 真人照片，属个人生物特征信息 |
| `webapp/data.db`（若你手动拷入） | 含检测记录与打卡数据 |

公开的 GitHub 仓库**不含**以上任何内容（均已在 `.gitignore` 排除），这是正确的做法。

## 六、环境变量速查

本包根目录附有 `.env.example`，列出了全部可调项。常用几个：

| 变量 | 默认 | 用途 |
| --- | --- | --- |
| `CAMERA_INDEX` | `1` | 本地摄像头索引 |
| `CAMERA_SOURCE` | 空 | 网络视频流地址（设置后优先于 `CAMERA_INDEX`） |
| `FLASK_SSL_CERT` / `FLASK_SSL_KEY` | 空 | 证书路径，设置后启用 HTTPS |
| `APP_DEV_SERVER` | 空 | 设为 `1` 改用 Flask 开发服务器（仅调试用） |
| `PYTHON_BIN` | 空 | 指定 `run_web.bat` 使用的解释器 |

> `run_web.bat` 已内置 `FLASK_SSL_CERT=certs/cert.pem`、`FLASK_SSL_KEY=certs/key.pem` 与 `CAMERA_INDEX=1`，
> 一般不需要额外设置。

## 七、验证是否一切正常

```bat
.venv\Scripts\python tests\test_unit.py
```

应输出 `187/187 通过`（其中 1 项因未打包数据集而自动跳过，属正常）。

这个测试**不需要启动服务、也不需要 GPU**，是判断「依赖是否装全」最快的方式 ——
它跑通，就说明环境没问题了。
